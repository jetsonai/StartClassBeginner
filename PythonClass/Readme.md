# AI 개발자를 위한 파이썬 기초

무인 키오스크 하나를 파이썬으로 조금씩 만들어 가며 배우는 입문 강좌의 실습 노트입니다.

## 사용 방법

1. 아래 표에서 **Open in Colab** 배지를 누르면 Colab에서 바로 열립니다. 설치할 것은 없어요.
2. 열리면 먼저 **[파일] → [Drive에 사본 저장]**을 누르세요. 그래야 수정한 내용이 내 드라이브에 저장됩니다.
3. **실습 노트**는 영상을 보며 직접 코드를 입력하는 노트예요. ✏️ 표시가 있는 칸에 입력하세요.
4. 막히거나 복습할 때는 **정답 노트**를 열어 보세요.
5. 셀은 위에서부터 순서대로 실행하세요. 연결이 끊겼다면 처음부터 다시 실행하면 됩니다.
